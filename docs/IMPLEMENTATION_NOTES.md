# Implementation Notes

- **Single Binary Architecture**: `tailfile` consolidates background node hosting (`tailfile agent`, `tailfile service ...`) and the MyGo GUI (`tailfile`) into one pure-Go module (`tailfile.local`, `CGO_ENABLED=0`).
- **In-Process Transport (`internal/agent/memtransport.go`, `embed.go`)**: Uses an `io.Pipe`-backed `http.RoundTripper` setting `RemoteAddr = "127.0.0.1:0"` and keeping `Base = "http://127.0.0.1:8645"` so existing localhost checks pass with zero TCP listeners and zero disk `gui-token` writes when running embedded.
- **State Lock Ordering (`internal/agent/statelock*.go`, `run.go`)**: `tailfile agent` binds the loopback TCP listener AND acquires `<StateDir>/agent.lock` (`flock` / `LockFileEx` + per-process guard) before calling `writeGUIToken` or `startTsnet`, preventing a second launch from clobbering an active daemon's bearer token.
- **Legacy Service & State Migration**: `tailfile service install|uninstall` automatically removes legacy `tailfile-agent` (`systemd`/`launchd`) and `TailfileAgent` (Windows Task Scheduler) registrations. `internal/gui/persist.go` saves to `<StateDir>/ui.json` (`0600`) and reads fallback UI preferences from legacy `<StateDir>/nsh-ui.json` and `<UserConfigDir>/tailfile/nsh-preview/ui.json`.
- **Origin Enforcement (`internal/agent/auth.go`)**: Accepts native callers with empty `Origin`, `tailfile://localhost`, and `tailfile://tailfile`; rejects retired `nsh://` and arbitrary web origins.
